Quick start

Anonymize an image

A simple cURL request is all you need to get started.

POST /images/anonymize

curl -X POST \
"https://blurstuff.up.railway.app/api/v1/images/anonymize?targets=faces&mode=pixelate" \
-F "file=@original.jpg" \
--output anonymized.jpg
